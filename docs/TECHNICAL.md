# Лист / LoveRead Studio

Графический интерфейс для локального клона
[loveread_book_multiparser](https://github.com/premiumpodpiska3454-debug/loveread_book_multiparser).
Исходный репозиторий находится в `upstream/`, его файлы оставлены без изменений.
Адаптер `gui/backend.py` использует адрес сайта, сессию HTTP и задержки оригинала;
добавляет прогресс, отмену, извлечение абзацев и проверку полноты загрузки.

## Запуск

Двойной щелчок по **LoveRead Studio** на рабочем столе или:

```bash
bash start.sh
```

Зависимости устанавливаются командой `bash install.sh` из корня проекта.
Подробная инструкция и системные пакеты перечислены в [README.md](../README.md).

## Скачать книги

1. Вставьте ID книг через запятую, например `2334, 1234`, или ссылки:
   `https://loveread.ec/view_global.php?id=2334` / `https://loveread.ec/read_book.php?id=2334&p=1`.
2. Нажмите **В очередь**, затем **Скачать и очистить**.
3. Программа последовательно загружает страницы и сохраняет каждую книгу
   отдельным PDF в `~/Desktop/Книги-LoveRead` (папку можно поменять).
4. Выберите готовую книгу в очереди, чтобы просмотреть и при желании
   отредактировать текст. **Сохранить PDF** создаёт новую копию.

Ссылка на любую страницу чтения начинает загрузку с первой страницы книги.
Повторные ссылки на тот же ID не добавляются в очередь.
Название и автор определяются по разметке; если название не найдено,
используется `Книга ID`. Ссылки других сайтов не поддерживаются.

## Чистый текст

- В PDF нет меню сайта, рекламных блоков, HTML-тегов и служебных сообщений программы.
- Невидимые символы, мягкие переносы, лишние пробелы и пустые строки удаляются.
- Абзацы, заголовки внутри книги, диалоги, кавычки и авторская пунктуация сохраняются.
- Номера сносок `[1]` по умолчанию остаются. Их удаление включается отдельным флажком.
- Книги сохраняются сразу в PDF: формат A5, встроенные шрифты с кириллицей, заголовки и номера страниц. Текст можно выделять и копировать.
- Длинные абзацы автоматически переносятся между страницами. Ранее сохранённые PDF не перезаписываются.

Можно открыть собственный TXT / HTML или перетащить его в окно, очистить,
отредактировать и сохранить в PDF. Для TXT распознаются UTF-8, UTF-16 с BOM и Windows-1251.

## Ошибки и остановка

Загрузка работает в отдельном потоке, окно остаётся доступным.
**Остановить загрузку** прерывает её после текущего HTTP-запроса или сразу во время паузы.
При закрытии работающего окна сначала запрашивается остановка потока.
Завершённые книги сохраняются; текущая при отмене не выдаётся за готовую.

Если часть книги скачана, а очередная страница недоступна или неожиданно повторилась,
собранный текст сохраняется с префиксом **[НЕПОЛНАЯ …]** в имени файла.
В очереди такая книга отмечается **Неполная**, а в журнале видна причина.
Нажмите **Скачать и очистить** повторно, чтобы попробовать загрузить её с начала.
Без пагинации конец определяется по повтору текста или HTTP 404 следующей страницы;
пустая страница или другая ошибка не считаются подтверждением полноты.
Отказ сайта HTTP 401/403/429 отображается как ошибка.

## Проверка

```bash
cd /путь/к/папке/проекта
python3 -m unittest discover -s tests -v
```

30 проверок: очистка текста, кодировки, сохранение без перезаписи, нормализация ID,
пагинация, короткая последняя страница, повторы и обрывы, отмена, работа очереди,
редактирование и сохранение PDF из GUI, встроенные шрифты, извлечение кириллицы, длинные абзацы и сохранность всех абзацев на нескольких страницах. Используются собственные короткие тексты
и подставные HTTP-ответы. Интерфейс также проверен через Qt offscreen на разных размерах окна.
Сеть терминала помощника ограничена: реальная загрузка с LoveRead здесь не проверена.
