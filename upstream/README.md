# 📚 MULTI BOOK DOWNLOADER

> ⚡ **Автоматичне завантаження текстів книг у TXT — кілька ID, одна команда, окремий файл для кожної книги.**

---

# 🚨 УВАГА — ПРОЧИТАЙ ПЕРЕД ВИКОРИСТАННЯМ!

Цей інструмент призначений для **автоматичного отримання тексту веб-сторінок книг**.

Використовуй його лише для матеріалів, які ти маєш право завантажувати та обробляти.

**Не використовуй скрипт для обходу обмежень доступу, захисту або масового копіювання матеріалів, якщо це заборонено правами правовласника чи правилами сайту.**

Також враховуй навантаження на сайт: скрипт спеціально використовує паузи між запитами.

---

# 🚀 Що це?

**Multi Book Downloader** — консольний Python-інструмент для автоматичного завантаження тексту книг із підтримуваних сторінок сайта.

Тобі достатньо вказати:

```text
🆔 ID книг
📁 папку для збереження
```

А далі програма сама:

```text
🔎 знаходить кількість сторінок
        ↓
📄 завантажує сторінки
        ↓
🧹 очищає текст
        ↓
💾 створює окремий TXT
        ↓
📊 показує результат
```

# 🎯 Як це працює?

## 1️⃣ Вводиш ID

Програма запитує:

```text
Введите ID книг через запятую:

Например: 2334, 1234, 5678

ID:
```

Вводиш:

```text
2334, 1234, 5678
```

---

## 2️⃣ Вказуєш папку

Наприклад:

```text
/home/user/books
```

або:

```text
~/books
```

Папка буде створена автоматично, якщо її ще немає.

---

## 3️⃣ Програма сама визначає сторінки

Тобі **не потрібно вручну вводити кількість сторінок**.

Скрипт аналізує першу сторінку та шукає пагінацію.

Наприклад:

```text
🔎 Определяю количество страниц для ID 2334...

📄 Найдено страниц: 47
```

---

# 📥 Завантаження

Під час роботи видно прогрес:

```text
======================================================================
📚 КНИГА ID: 2334
📄 Страниц к загрузке: 47
💾 Файл: /home/user/books/book_2334.txt
======================================================================

[  1/47] Загружаю... ✅
[  2/47] Загружаю... ✅
[  3/47] Загружаю... ✅
...
[ 47/47] Загружаю... ✅
```

Ти завжди бачиш, на якому етапі знаходиться завантаження.

---

# 🧠 Розумне визначення кінця

Скрипт не просто бездумно качає тисячі сторінок.

Він перевіряє:

* 🔎 чи є текст;
* 📄 чи існує сторінка;
* 🔁 чи не повторюється попередній текст;
* 📊 скільки сторінок було визначено.

Якщо текст закінчився:

```text
✋ Текст закончился
```

Якщо сайт повернув повторну сторінку:

```text
✋ Повтор страницы
```

завантаження конкретної книги припиняється.

---

# 🧹 Очищення тексту

Отриманий HTML перетворюється на звичайний текст.

Скрипт:

```text
🌐 HTML
  ↓
🔎 textBook
  ↓
🧹 очищення
  ↓
📝 чистий TXT
```

Прибираються зайві порожні рядки та пробіли.

# 🛡️ Захист від помилок

```text

```

### 💾 Помилки збереження

```text
❌ Ошибка сохранения
```

### 📄 Відсутність тексту

```text

```

### 🔁 Повтор сторінки

```text

```

### ⌨️ Ctrl+C

Якщо потрібно зупинити програму:

```text
Ctrl + C
```

```text

```

---

# ⏳ Пауза між запитами

У програмі передбачена затримка:

```python
PAGE_DELAY = 1.5
```

тобто між завантаженнями сторінок є пауза.

Також між книгами:

```python
BOOK_DELAY = 3
```

Це зменшує інтенсивність запитів до сервера.

---

# ⚙️ Налаштування

На початку скрипта можна змінити:

```python
PAGE_DELAY = 1.5
BOOK_DELAY = 3
```

### `PAGE_DELAY`

Пауза між сторінками.

### `BOOK_DELAY`

Пауза між книгами.

Також є захисний ліміт:

```python
FALLBACK_MAX_PAGES = 1000
```

Він використовується лише тоді, коли автоматично визначити пагінацію не вдалося.
